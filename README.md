# LazyGarden

Native Android match-3 and estate-restoration game.

## Current playable build
- Native Match-3 campaign with persistent board/progress.
- Seven estate restoration tasks and story beats.
- Authored 2D garden artwork replaces the former primitive prototype garden scene.
- LazyGarden launcher branding is declared in the Android manifest.
- Localized core controls in English, Albanian, German, French, Italian, Spanish, Portuguese, Turkish and Bosnian.

The project uses original/generated LazyGarden artwork and does not include proprietary Gardenscapes code or assets.
