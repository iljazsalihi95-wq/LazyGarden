# Native restoration and optional rewards (0.10.0)

Task order is fountain → chosen flowers → path → bench → greenery → entrance → facade. Each scene completes through its own timeline callback. Activity pause, detach and recreation checkpoint elapsed milliseconds. Beginning a task spends its cost once; finishing is guarded by `constructing`. Completed flowers and object artwork are rendered in the estate. Archive replay has no economy callbacks.

Scene 2 keeps its original picker/timeline, adds textured flower/soil art, gardening pose frames, TTS, particles and lifecycle wiring. Scenes 3–7 share rendering/lifecycle utilities but have independent ordered work plans, dialogue, tools, transformations and routes. `PathSequence` remains an adapter to the path plan.

Match-3 introduces crates at 8, two-impact stones at 26, soil at 51, flowers needing adjacent water matches or direct power-ups at 76, falling parcels at 101, birds at 126. Clearing tiles below moves the cargo toward the bottom. Engine goals gate the win; the objective arrays, cargo and rescue counts round-trip in the extended save. Legacy 138-token boards keep their original goals until the next level. The campaign still needs wider human difficulty balancing; the presence of 250 definitions is not evidence of 250 hand-balanced levels.

Rewarded video is voluntary. Unity game `6209382`, placement `Rewarded_Android`, SDK 4.16.6 (compatible with the current Kotlin 2.0 toolchain). Interstitial/banner placements are retained as configuration constants but are never shown. Starting/loading/clicking/skipping/failing a video grants nothing. Unity COMPLETED or AdMob earned-reward settles a durable one-use receipt. Repeated callbacks cannot grant twice. Optional rewards: 100 Coins, one restoration star, one life, or five saved-board moves after failure. These are virtual resources with no cash value.

AdMob unit: `ca-app-pub-9794339868092490/5304189686`. **The publisher's AdMob app ID was not supplied.** Fallback remains disabled unless built with `-PadmobAppId=ca-app-pub-…~…`; a Google sample app ID only satisfies manifest validation while disabled, and is not a fabricated publisher ID. `-PadsTestMode=true` enables SDK test mode for integration testing. Default Unity configuration uses the supplied live game/placement. Device tests do not request or click live ads. Actual ad fill/revenue is not established by callback tests.

Dialogue locale options: sq, de, it, mk, tr. Work-scene text and TTS use the selected language; menus/story archive are still primarily Albanian. If an installed TTS engine lacks a language it stays silent rather than reading it in a different language. Four resident identities have new work poses; the broader twelve-character cast still needs individual sprite production. The extra work poses are discrete sprite frames, not skeletal animation or recorded actors.
